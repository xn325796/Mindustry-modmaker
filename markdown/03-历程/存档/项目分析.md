# Mindustry ModMaker 项目分析

> 分析日期：2026-10-03 · 基于实际代码与环境核查（非文档转述）

## 一、项目定位

节点画布式的 Mindustry（像素工厂）模组构建器 —— Java + JavaFX 桌面应用（非 Electron）。核心能力闭环：

- **读入**已有模组包（.zip / 文件夹）→ 解包成可编辑项目，画布上按类型分列卡片、按引用关系连线
- **编辑**：schema 驱动的字段检查器（全中文）、字符串表、校验、撤销/重做
- **输出**可被游戏直接加载的完整模组，**未改动的文件字节级原样保留**

核心不变式：`项目文件夹 = 真实模组文件夹 + modmaker/ 创作层`。由此推出「构建 = 复制」「项目可直接丢进 mods/ 实机跑」，没有第二套生成逻辑。

## 二、规模与技术栈

| 维度 | 实测数据 |

| 主代码 | 62 个文件 / 9628 行 |
| 测试 | 22 个文件 / 2492 行 / 105 个测试方法 |

| 分层 | `core/`（纯 Java 零 JavaFX，可离线单测）+ `ui/`（JavaFX）+ `tools/` |

> 注：文档数字已滞后 —— README 写「57 个测试」、receiving.md 写「70 个」，**实测 105 个**。

## 三、设计亮点

1. **严格分层**：格式内核 `core/` 零 UI 依赖、可离线单测；UI 只通过 `ProjectController` 唯一致变入口订阅通知。
2. **无损往返**：`raw` / `metaText` / `bundleRaw` 存原文（含 BOM），未编辑内容按字节回写，有 955 文件逐字节比对的金标测试锁住。
3. **格式契约严谨**：9 类可文件化内容、目录决定类型、补丁省略 type、精灵前缀规则等，全部有 Mindustry 源码行号依据。
4. **确定性**：记录排序、zip 固定时间戳、画板名存 project.json，保证重复保存/构建逐字节稳定。
5. **深度移植**：`SimplexNoise`、`PlanetMeshes` 逐参数移植原版算法，用反射比对逐位一致来锁定。
6. **测试分层完整**：格式规则 → 容错解析 → 导入 → 金标往返 → 恶意输入（假 zip / 路径穿越）→ UI 场景图 + 像素断言。

## 四、现状问题与风险（均已实地核查）

### 1. 环境路径断链（最紧迫）
项目从 `Desktop\mindustry\Mindustry-modmaker` 移到了 `Desktop\Mindustry-modmaker`，兄弟目录布局变了：

- 测试夹具 `../格雷工业` → **不存在**，依赖它的约 22 个金标往返测试会**静默 skip**（别把 skip 当全绿）
- `schemaBootstrap` 默认源 `../Mindustry-160.5/...` → **不存在**；真实源码在 `Desktop\Mindustry\Mindustry-160.5\...`（深一层）。好在 `schemas/` 三个生成物已存在，不影响运行，只影响再生成
- 实机游戏 jar 在 `Desktop\Mindustry\Mindustry\Mindustry.jar`，与默认 `../Mindustry/Mindustry.jar` 的层级对不上

### 2. 无版本控制
`.git` 已初始化但 **0 提交**，全部文件 untracked。9600 行代码没有任何历史保护，风险高。

### 3. 文档滞后
测试数（57/70 vs 实际 105）、启动脚本名（文档写 `启动ModMaker.bat`，实际是 `run.bat`）、项目路径都已过期。

### 4. 已知功能短板（文档自述）
校验消息未汉化、精灵导入/预览未做、大项目导入在 UI 线程同步（955 文件约 2.7s）、连线堆叠数量固定为 1。

## 五、改进建议（按优先级）

1. **立即 `git` 首次提交** —— 成本最低、收益最高的保护措施。
2. **修复路径探测**：让 `TestFixtures.realModRoot()` 和 `schemaBootstrap` 的候选位置覆盖新的 `Desktop\Mindustry\...` 布局，或把夹具放回；确认金标测试恢复运行而非 skip。
3. **对齐文档**：更新测试数、脚本名、项目路径三处。
4. 后续再考虑校验消息汉化、精灵面板续建、异步导入等功能项。

## 六、结论

设计严谨、测试扎实的高质量个人项目；格式内核的「无损往返 + 确定性」是最大亮点。当前短板不在代码本身，而在**工程外围** —— 项目移动导致的路径断链、零 git 提交、文档滞后。
