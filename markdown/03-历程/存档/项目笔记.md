# Mindustry ModMaker 项目笔记(2026-10-05)

> 承接《项目分析-2026-10-03》。本篇记录 10-04 ~ 10-05 两天的改进全量情况、验证方式与遗留清单。

## 一、本次改动总览(按主题)

### 1. 数据安全与核心循环(10-04 阶段1)

- **校验面板复活**:`IssuesPane` 订阅项目变化实时刷新(原来只在构造时刷一次,列表永远为空),改一条警告立即消失。
- **资产表联动**:ItemsPane 表格选中 → 检查器(原来根本没接);编辑字段不再丢选中高亮;画布选中时表格反向高亮滚动。
- **撤销覆盖补全**:`setField` / `setString` / `rename` / `addBoard` / `tidyLayout` 全部进撤销栈(原来对最高频操作无效);同字段快速连续编辑合并为一步;redo 改为 Ctrl+Shift+Z。
- **画布批量删除**:框选多卡一次删除,单个撤销步恢复。
- **脏标记 + 退出保护**:状态栏"(有未保存的修改)";菜单退出和窗口 X 都拦截确认;`boardsDirty` 覆盖拖拽/整理等纯画布改动。
- **导出安全**:`ModExporter.buildFolder` 清理目标目录里项目已删除的旧文件(修"删除的内容在成品里复活"),清理项进报告;导入/新建/导出覆盖已有目录先确认;导出完成弹窗带"打开文件夹"。

### 2. 节点卡片可读性(阶段2)

- 卡片高度按内容自适应(原 260×130 硬编码);字段预览按关键字段优先,超长省略号+tooltip;标题栏按类型着色;连线加箭头(独立顶层 arrowLayer,不被卡片遮挡);端口标签 >4 个显示 "+n";缩放 LOD 分级(0.5/0.25 两档)。
- **修复隐藏 bug**:端口标签/连线标签因非受管 Label 尺寸恒 0×0 **从未渲染过**——改用几何自绘 Text 或 autosize 后正常。
- refresh 改按节点 id 增量更新,保留多选/悬停/边选中状态。

### 3. 星球预览保真(阶段3 + 10-05 对齐)

- 噪声移植本就忠实;差异在渲染层:网格改用 `mesh.divisions`(顺修 octaves 解析 bug)、vanilla 星球移植 SerpuloPlanetGenerator 地表色表(19 种方块色直接采样自 v8 官方贴图中心像素,albedo 一并移植)、光照改游戏公式(昼夜 + 反照率镜面)、大气改渐变光晕(贴真实轮廓,山谷透光)、MultiMesh 全层、星空背景。
- **对齐实机的关键修复**:半径小于星球的图层(如格雷工业端点星的红色 cloudMesh radius=0.65 < 0.9)游戏里被深度缓冲遮住,预览现在同样跳过;去掉瓦片描边与外观页 sector 网格。
- `PlanetOrbits` 接入显式 `orbitRadius`(原来只按公式推算,改字段预览永远不动)。

### 4. 生产流程反馈(阶段4)

- 校验 error 时构建/打包/试玩先确认;错误弹窗带异常类名(null 兜底)。
- 导入报告:skipped / parseFailures 文件列出(原来完全不可见)。
- GameLauncher:游戏输出**流式**推日志(闪退当场可见,匹配面扩大到异常栈);新增"停止游戏"/"打开测试目录";jar/JDK 找不到时文件选择器兜底。
- Ctrl+F 全局搜索(回车循环跳转+画布平移到卡)、F5 校验 / Ctrl+B 构建 / F6 试玩。
- StringsPane:按键/值过滤、缺失翻译标红+计数、extra key 只读可见。
- 静默降级提示:首次编辑导入文件提示"将重写为标准 JSON";数字/颜色输入无效行内标红且不提交。

### 5. 节点画布重构 · 物品/液体轻量载体卡(10-05)

- **CarrierCard**:物品/液体节点不再渲染完整内容卡,改为 64px 紧凑卡(色条+名称+类型徽标+下拉)。下拉候选 = 本模组已注册记录 + 原版物品(22)/液体(11)。
- 下拉选定即改绑:选记录 → 节点改绑记录 id;选原版 → 新模型字段 `refName`/`refType`(随 .canvas 持久化,Obsidian 兼容)。改绑可撤销,连线自动重解析。
- 载体卡只保留右侧 ID 输出端口;省掉字段预览、引用端口和每卡两次 schema 继承链扫描——300 内容模组(近半是物品/液体)画布场景图约减半。
- **Delete 载体卡 = 只摘节点**(可撤销),记录留在资产表;资产表删除按钮才真删记录。
- 旧项目零迁移:渲染按记录类型决定,老板子自动呈现为载体卡。
- `CanvasCard` 接口统一两种卡的画布几何 API;refresh 的 `contentById` O(N²) 改为每轮一次 id→记录索引。

## 三、遗留清单(按价值排序)

1. **bundle 原位替换保留注释**:改任一 locale 字符串仍会按键序重写整个 bundle 文件丢注释(需重写 PropertiesFile 读写为按行定位替换)——最有价值的下一个大项。
2. StringsPane 编辑仍是全表重建,长表输入可能被打断(局部更新)。
3. 大模组导入仍同步跑 UI 线程(955 文件约 2.7 秒)。
4. 检查器"类"切换与改名仍是提交制(非逐键),属有意为之。
5. 运行时状态字段(wasShooting/lastX/p1 等约 30 个)仍在 schema 中显示,可在 schema 层加排除清单。
6. 金标测试夹具路径:把 `Desktop\社会主义工业化` 加入 TestFixtures 候选,让 23 个 skip 变成真跑。
7. git:仓库仍在 Desktop 一级且零提交(10-03 分析的首要风险,至今未处理)。
